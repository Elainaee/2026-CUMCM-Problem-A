\begin{center}
{\LARGE\bfseries 圆柱形药材烘干过程的传热传质建模与求解}\\[1.5em]
{\large\bfseries 摘~~要}\\[0.8em]
\end{center}

干燥是决定中药材成品品质的关键工序，热风烘干包含预热平衡与恒温干燥两个阶段。本文以长
$25\ \mathrm{cm}$、半径 $2\ \mathrm{cm}$ 的圆柱形药材为对象，建立内部温度场与水分浓度场时空
演化的数学模型，采用守恒型\textbf{有限体积法}离散空间、隐式格式推进时间，进而确定满足含水率
指标的烘干时长。

\textbf{针对问题一}，因长径比 $L/R=12.5$、轴向端部效应可忽略，将药材退化为
\textbf{无限长圆柱}，建立径向一维非稳态传热--传质模型：温度场由 Fourier 定律描述，水分场由
Fick 第二定律描述，中心轴取零通量条件，表面取 Robin 型对流换热与对流传质条件；烘房时变环境
取自附件1，并经 \textbf{Savitzky--Golay 保形滤波}平滑。本问 $\rho,c_p,k$ 为
常数且 $D$ 仅依赖 $C$，传热与传质\textbf{解耦}，故空间以有限体积法离散、时间以
\textbf{Crank--Nicolson} 格式推进，传质方程因 $D(C)$ 非线性每步施行 \textbf{Picard 迭代}。
结果表明 $1800\ \mathrm{s}$ 时表面温度升至 $\mathbf{36.7710\ ^\circ C}$、中心仅
$\mathbf{33.5711\ ^\circ C}$；表面含水率降至 $\mathbf{1.5102\ kg/kg}$，距中心
$1\ \mathrm{cm}$ 以内仍高于 $2.53\ \mathrm{kg/kg}$，呈明显\textbf{“干壳湿芯”}特征。

\textbf{针对问题二}，恒温干燥阶段 $\rho,c_p,k$ 均随含水率变化、$D$ 含 Arrhenius 温度项，传热与
传质\textbf{双向耦合}；且过程长达 $2\sim3$ 天，端部效应不可忽略，故不作降维，直接在柱坐标下
建立\textbf{三维模型}，径向 $20\times$ 周向 $6\times$ 轴向 $32$ 共 $3840$ 个控制体，面通量以
\textbf{调和平均}折算面导率，采用\textbf{后向欧拉}格式（$\Delta t=5\ \mathrm{s}$）配合
\textbf{Picard 迭代}与\textbf{共轭梯度法}求解。两阶段分界时刻 $t_c$ 题目未给出，本文以尾段中位
温度与 MAD 给出稳态温度带，结合 $20\ \mathrm{min}$ 滑动均温与升温斜率双条件及 $30\ \mathrm{min}$
持续性要求，识别得 $\mathbf{t_c=6780\ s=1.8833\ h}$；切换处只换物性参数、不重置初值。结果表明
$3\ \mathrm{h}$ 时中心温度 $\mathbf{49.8952\ ^\circ C}$、径向温差收缩至
$0.06\ ^\circ\mathrm{C}$；中心含水率 $\mathbf{1.9237\ kg/kg}$、表面
$1.0791\ \mathrm{kg/kg}$，呈“内湿外干”分布。

\textbf{针对问题三}，因含水率沿径向由外向内递增，中心 $r=0$ 处最高且下降最慢，故“各处水分
浓度均低于 $0.15\ \mathrm{kg/kg}$”等价于中心含水率达标。在二维轴对称模型上采用二阶段
\textbf{Gauss--Legendre 隐式 RK4} 推进（$\omega=0.8$ 阻尼不动点迭代，
$\Delta t=2.5\ \mathrm{s}$），以守恒型有限体积格式保证水分守恒；当全域最大含水率首次低于
$0.15\ \mathrm{kg/kg}$ 时插值细化，得烘干总时长 $\mathbf{t_{\mathrm{dry}}=56.9702\ h}$，
此时全域最大含水率为 $\mathbf{0.1446\ kg/kg}$。

\textbf{针对问题四}，考虑水分流失导致的尺寸收缩：由附件2 的半径数据取
\textbf{均匀径向收缩、轴向长度不变}（半径 $R(t)$ 收缩至约 $1.2\ \mathrm{cm}$，轴向仍为
$25\ \mathrm{cm}$），求解域外边界随时刻移动，构成\textbf{移动边界问题}。采用归一化坐标
$\xi=r/R(t)$ 把移动区间映射到固定区间 $[0,1]$，径向扩散项因此出现 $1/R^2(t)$ 几何因子；
含水率取\textbf{干基}定义并视为随固体骨架一起运动，控制方程\textbf{不引入体积浓度稀释项}；
物性自初始时刻起统一采用附录4。以径向 $96\times$ 半轴向 $80$ 个控制体离散，面扩散系数取
Kirchhoff 积分均值，时间以\textbf{自适应 BDF} 推进，并以全域最大含水率首次低于
$0.15\ \mathrm{kg/kg}$ 为终止事件，得烘干时长
$\mathbf{t_{\mathrm{dry}}=51.0908\ \mathrm{h}}$（$183927\ \mathrm{s}$），此时半径收缩至
$1.2000\ \mathrm{cm}$、全域最大含水率 $0.14999987\ \mathrm{kg/kg}$。

\medskip
关键词:\textbf{药材烘干~传热传质~有限体积法~移动边界~隐式 Runge--Kutta 法}

\section{问题重述}
\subsection{问题背景}

中药材干燥是决定成品品质的关键工序之一，热风烘干因其设备简单、操作方便而被广泛采用。
热风烘干过程一般包含\textbf{预热平衡}与\textbf{恒温干燥}两个阶段，通过调控烘房内的温度与
水分浓度（含湿量）环境完成药材的脱水。若工艺参数选取不当，容易出现干燥效率低、能耗高、
成品品质不稳定等问题；而传统的试验优化方法成本高、周期长。因此，需要借助数理分析与数值
仿真手段，建立药材烘干过程中温度场与水分浓度场的变化规律模型，为工艺优化提供依据。本文
以圆柱形中药材为研究对象，在已知烘房温湿度时变环境与药材物性参数的条件下，求解药材内部
温度与水分浓度的时空分布，并进一步确定满足干燥指标所需的烘干时间。

在不改变原题意的前提下，将赛题重述为如下四个子问题：

    $2\ \mathrm{cm}$ 的圆柱形药材，烘干开始时温度为 $28\ ^\circ\mathrm{C}$、水分浓度
    （干基含水率）为 $2.55\ \mathrm{kg/kg}$。在附件1给出的烘房温度与水分浓度时变环境下，
    建立预热平衡阶段药材温度与水分浓度变化规律的数学模型（物性参数见附录2），并按表1、表2
    格式给出 $100\sim1800\ \mathrm{s}$ 内若干指定时刻、距药材中心 $0\sim2\ \mathrm{cm}$
    处的温度与水分浓度，完整结果按要求保存至 result1.xlsx，所有结果保留四位小数。
    \item \textbf{问题二（整个烘干过程建模与求解）}：烘干过程通常持续 $2\sim3$ 天，
    预热平衡与恒温干燥两阶段的工艺参数有所不同。建立整个烘干过程中药材温度与水分浓度变化

    保存至 result2.xlsx。
    \item \textbf{问题三（满足含水率指标的烘干时间）}：以药材各处水分浓度均低于

\section{问题分析}
本文研究圆柱形中药材在热风烘干过程中温度场与水分浓度场的时空演化规律。四个子问题由浅入深、
层层递进：问题一建立预热平衡阶段的基础传热--传质模型；问题二将其推广至持续 $2\sim3$ 天的
完整烘干过程，并引入随温湿度变化的物性参数；问题三在问题二模型的基础上确定满足含水率指标的
烘干时间；问题四进一步考虑水分流失引起的尺寸收缩，将固定域问题推广为移动边界问题。

\subsection{问题一的分析}
问题一属于\textbf{非稳态传热--传质}问题，在数学上归结为圆柱域上一组抛物型偏微分方程的初边值
问题。其难点有二：药材长径比很大（$L/R=12.5$），直接三维瞬态求解代价过高，需作几何降维；
烘房温湿度为时变边界条件，且实测数据含测量噪声，需先平滑处理。

\textbf{建模思路}：因 $L\gg R$，忽略轴向端部效应与周向不均匀性，将圆柱药材退化为\textbf{无限长
圆柱}，问题降维为一维径向问题，仅研究 $r\in[0,R]$。温度场由 Fourier 定律描述，水分场由 Fick
第二定律描述；中心轴由轴对称性给出零通量条件，表面为 Robin 型对流边界，环境时变量 $T_a(t)$、
$C_a(t)$ 取自附件1 并经 Savitzky--Golay 平滑。

\textbf{求解思路}：附录2 中 $\rho,c_p,k,h,h_m$ 均为常数、$D$ 仅依赖 $C$ 而与 $T$ 无关，故传热
与传质\textbf{解耦}，可分别独立求解。空间采用\textbf{有限体积法}（守恒形式）离散，时间采用
\textbf{Crank--Nicolson} 格式；传质方程因 $D(C)$ 非线性，每步以 \textbf{Picard 迭代}线性化。

\subsection{问题二的分析}
问题二将研究范围由 $30$ 分钟的预热阶段扩展到持续 $2\sim3$ 天的\textbf{完整烘干过程}。相较
问题一，本问的本质变化可归结为四点。

其一，\textbf{控制方程不再解耦}：附录3 中 $\rho,c_p,k$ 均随含水率 $C$ 变化，$D$ 还含 Arrhenius
温度项，$\rho c_p$ 不能提到时间导数之外，传热与传质\textbf{双向耦合}。

其二，\textbf{几何不能再降维}：问题一降维的依据是 $30\ \mathrm{min}$ 的预热尺度远小于轴向扩散
的特征时间；恒温干燥持续数天，端面交换经轴向扩散向内渗透，端部效应不再可忽略，且物性随
$C,T$ 变化后也失去了严格的轴对称依据。

其三，\textbf{阶段分界时刻需识别}：两阶段物性公式不同，而 $t_c$ 题目并未给出，须依据附件1
的实测温度判定；单一温度阈值易被测温噪声提前触发，需要更稳健的判据。

其四，\textbf{环境需外推、时间跨度大}：附件1 仅覆盖前 $4\ \mathrm{h}$，其后须以恒温段平台均值
外推；全过程长达数天，需兼顾数值稳定性与计算效率。

\textbf{求解思路}：在\textbf{三维柱坐标有限体积}框架下联立求解两方程，两阶段物性按识别出的
$t_c$ 分段取用并保持切换连续。

\subsection{问题三的分析}
问题三在问题二模型的基础上引入\textbf{干燥达标判据}：药材各处水分浓度均低于
$C_{\mathrm{crit}}=0.15\ \mathrm{kg/kg}$。由于水分浓度沿径向由外向内递增，中心 $r=0$ 处最高、
下降最慢，故“各处均达标”等价于“中心含水率 $C(0,t)<0.15$”，多维达标判断归结为对中心点
时间序列的监控，问题转化为\textbf{临界时间的确定}。

\textbf{求解思路}：在问题二模型上作长时间推进，定时检测 $\max C$，首次达标即为烘干总时长；
为精确定位达标时刻，可先以较粗步长推进至接近达标，再通过\textbf{插值}细化。

\subsection{问题四的分析}
问题四考虑实际烘干中因水分流失导致的\textbf{尺寸收缩}。附件2 给出 $0\sim72\ \mathrm{h}$ 内药材
半径由 $2.0\ \mathrm{cm}$ 收缩至约 $1.2\ \mathrm{cm}$，即求解域外边界 $R(t)$ 随时刻\textbf{移动}，
构成移动边界问题；物性参数改用附录4 的经验公式（系数与附录3 不同）。

难点在于：半径收缩使空间离散域逐时刻变化，固定网格难以直接套用；表6 要求输出到“药材表面”的
水分浓度，而该位置本身随时刻移动。

\textbf{求解思路}：采用\textbf{坐标变换} $\xi=r/R(t)$ 将移动区间 $[0,R(t)]$ 映射到固定区间
$[0,1]$，径向扩散项因此出现 $1/R^2(t)$ 几何因子；含水率取干基定义并视为随固体骨架运动，
故不引入体积浓度稀释项。半径 $R(t)$ 由附件2 数据经保形插值得到（不作外推），物性自初始
时刻起统一采用附录4，时间以自适应 BDF 推进，监测全域最大含水率首次低于
$0.15\ \mathrm{kg/kg}$ 即得烘干时长。

基于上述分析，问题一至问题三的完整求解路线如图~\ref{fig:roadmap} 所示：三者共用同一套
数据预处理与阶段分界识别，随后按各自的几何维度与物理假设建立模型、选取数值格式，最终输出
对应结果表并统一经过数值验证。

\section{模型假设}
结合药材物性与热风烘干的工艺特点，本文建模作如下假设：

\begin{enumerate}
    \item \textbf{连续介质与各向同性假设}：药材视为均匀、连续、各向同性的多孔介质，内部不
    存在生成或消耗热量与水分的内源项；同一时刻的物性仅随含水率（及温度）变化，不随空间位置
    变化。因此控制方程中不含源项，物性可作为状态量的函数统一写入。

    \item \textbf{导热与扩散定律假设}：药材内部的热传递服从 Fourier 定律，水分迁移服从 Fick
    第二定律，水分以浓度梯度驱动的扩散为主，忽略毛细力、压力梯度与重力引起的迁移，也不考虑
    水分以气态形式在孔隙内的独立流动。

    \item \textbf{对流边界假设}：药材表面与烘房空气之间以对流方式换热与传质，对流换热系数
    $h$ 与对流传质系数 $h_m$ 取附录给定的常数，不随温度、含湿量、风速及表面含水率变化。

    \item \textbf{环境均匀且单向作用假设}：烘房内温度与空气含湿量处处均匀，其随时间的变化
    规律由附件1 完全给定，且不因药材的吸放热与失水而改变。即环境构成一组给定的时变边界条件，
    药材的存在不影响烘房环境。

    \item \textbf{降维假设}：预热平衡阶段（问题一）持续时间短，轴向端部效应与周向不均匀性
    可忽略，药材退化为无限长圆柱，仅保留径向变化；恒温干燥持续数天，端面交换经轴向扩散向内
    渗透而不可忽略，故问题二保留完整三维模型，问题三利用几何与受载的轴对称性采用二维轴对称
    模型。

    \item \textbf{尺寸不变假设}：问题一至问题三中，药材在干燥过程中尺寸保持不变，即
    $R=2\ \mathrm{cm}$、$L=25\ \mathrm{cm}$ 为常数；因水分流失引起的尺寸收缩仅在问题四中予以
    考虑，并直接采用附件2 给出的半径随时间变化数据。

    \item \textbf{初始均匀假设}：烘干开始时，药材内部的温度与水分浓度处处均匀，分别为
    $T_0=28\ ^\circ\mathrm{C}$ 与 $C_0=2.55\ \mathrm{kg/kg}$。

    \item \textbf{分段物性假设}：预热平衡阶段的物性取附录2 给出的常数，恒温干燥阶段的物性取
    附录3 给出的随含水率变化的关系式；两阶段以识别出的临界时刻 $t_c$ 为界切换，切换处只更换
    物性参数而不重置状态量，保证温度场与水分浓度场连续。

    \item \textbf{径向收缩与干基含水率假设（问题四）}：水分流失引起的几何变化取\textbf{均匀径向
    收缩、轴向长度不变}，即半径 $R(t)$ 直接采用附件2 给出的数据，轴向长度保持
    $L=25\ \mathrm{cm}$；含水率以\textbf{干基}定义（每单位干物质所含水的质量），视其为随固体
    骨架一起运动的量，故移动边界下的水分控制方程\textbf{不引入体积浓度稀释项}。问题四的物性
    自初始时刻起统一采用附录4 给出的关系式（其中扩散系数同时依赖温度与含水率），不再移植
    问题二用过的附录2$\to$附录3 阶段过渡；该过渡仅作敏感性对照。
\end{enumerate}

\textbf{2. 问题描述与几何简化}

预热平衡阶段，某圆柱形中药材（长 $L=25\ \mathrm{cm}$、半径 $R=2\ \mathrm{cm}$）置于烘房内，
初始温度 $T_0=28\ ^\circ\mathrm{C}$、初始水分浓度（干基含水率）$C_0=2.55\ \mathrm{kg/kg}$。
烘房温度 $T_a(t)$ 与空气含湿量 $C_a(t)$ 随时间的非稳态变化由附件1给出。
由于 $L\gg R$，忽略轴向端部效应，将药材视为\textbf{无限长圆柱}，问题退化为一维径向问题，
仅研究 $r\in[0,R]$ 方向的温度场与水分浓度场。

\textbf{3. 控制方程}

考虑药材内部的传热与传质过程。由于药材可近似视为圆柱体，且其长径比较大，因此忽略轴向温度梯度和水分梯度，并假设温度场与水分迁移过程均具有轴对称性。设 $T(r,t)$ 为时刻 $t$、径向位置 $r$ 处的温度，$C(r,t)$ 为时刻 $t$、径向位置 $r$ 处的水分浓度。

对于药材内部的热传递过程，根据 Fourier 热传导定律，并参考圆柱形物料干燥过程中的热质耦合模型~\cite{ref1}，在上述假设下，可得到圆柱坐标系下的径向一维非稳态热传导方程：

\begin{equation}
\rho c_p\frac{\partial T}{\partial t}
=\frac{k}{r}\frac{\partial}{\partial r}\left(r\frac{\partial T}{\partial r}\right),
\quad 0<r<R,\ t>0
\label{eq:heat}
\end{equation}

其中，$\rho$ 为药材密度，$c_p$ 为比热容，$k$ 为导热系数。
对于药材内部的水分迁移过程，根据 Fick 第二定律及扩散理论~\cite{ref3}，并参考圆柱形物料干燥过程中的传质模型~\cite{ref1}，在考虑有效扩散系数随水分浓度变化的情况下，建立水分传递方程。根据圆柱坐标系下梯度与散度算子的坐标变换关系~\cite{ref2}，并结合轴对称条件，可得到径向一维水分传递方程：
\begin{equation}
\frac{\partial C}{\partial t}
=\frac{1}{r}\frac{\partial}{\partial r}\left(r\,D(C)\frac{\partial C}{\partial r}\right),
\quad 0<r<R,\ t>0
\label{eq:mass}
\end{equation}

\begin{equation}
D(C)=7\times10^{-9}\,e^{-0.89/C}\quad(\mathrm{m^2/s}).
\label{eq:D}
\end{equation}

\textbf{4. 初始条件与边界条件}

初始时刻药材内部温度、水分浓度均匀：
\begin{equation}
T(r,0)=T_0,\qquad C(r,0)=C_0.
\label{eq:ic}
\end{equation}

中心 $r=0$ 处由对称性得：
\begin{equation}
\left.\frac{\partial T}{\partial r}\right|_{r=0}=0,\qquad
\left.\frac{\partial C}{\partial r}\right|_{r=0}=0.
\label{eq:bc_center}
\end{equation}

表面 $r=R$ 处为对流换热与对流传质边界：
\begin{equation}
-k\left.\frac{\partial T}{\partial r}\right|_{r=R}=h\bigl[T(R,t)-T_a(t)\bigr],
\label{eq:bc_heat}
\end{equation}
\begin{equation}
-D\left.\frac{\partial C}{\partial r}\right|_{r=R}=h_m\bigl[C(R,t)-C_a(t)\bigr].
\label{eq:bc_mass}
\end{equation}

\subsection{问题一模型的求解}
\textbf{1. 数值方法}

采用\textbf{有限体积法}（守恒形式）对方程 \eqref{eq:heat}、\eqref{eq:mass} 进行径向空间离散：
将柱坐标散度项写成通量守恒形式，控制体界面取几何坐标 $r_{i\pm1/2}$，得到三对角线性方程组。
时间方向采用 \textbf{Crank--Nicolson} 格式（对线性扩散方程，Crank–Nicolson 格式具有二阶时间精度，并具有良好的稳定性；对于当前含非线性扩散系数的耦合问题，其整体稳定性还需要结合具体离散方程和迭代过程分析~\cite{ref4}。）；由于 $D(C)$ 非线性，
传质方程每步采用 \textbf{Picard 迭代}（滞后系数）求解。环境温湿度 $T_a(t),C_a(t)$ 由附件1数据
经 Savitzky--Golay 平滑后线性插值得到。径向取 $N=1600$ 个节点（$\Delta r=1.25\times10^{-5}\ \mathrm{m}$），
时间步长 $\Delta t=0.25\ \mathrm{s}$。经网格与时间步加密验证，结果变化小于 $10^{-4}$，
满足四位小数精度要求。求解流程见算法~\ref{alg:p1}。

\begin{algorithm}[H]
\caption{问题一瞬态传热--传质数值求解}
\label{alg:p1}
\begin{algorithmic}[1]
\State 初始化：$T\gets T_0$，$C\gets C_0$，径向网格 $r_i=i\Delta r\ (i=0,\dots,N)$
\For{$n=1$ \textbf{to} $M$}
    \State $t_n \gets n\Delta t$；由附件1插值得到环境 $T_a(t_n),\,C_a(t_n)$
    \State 用 Crank--Nicolson 求解温度场 $T^{n}$（解三对角方程）
    \For{$k=1$ \textbf{to} $3$} \Comment{Picard 迭代}
        \State 由 $C^{n,k}$ 计算 $D(C)$，组装并求解水分场 $C^{n,k+1}$
    \EndFor
\EndFor
\State \Return 各时刻、各径向位置的温度 $T$ 与水分浓度 $C$
\end{algorithmic}
\end{algorithm}

$D(C_0)=7\times10^{-9}e^{-0.89/C_0}\approx4.9\times10^{-9}\ \mathrm{m^2/s}$ 仍然很小，
$30\ \mathrm{min}$ 内水分扩散的特征深度 $\sqrt{Dt}\approx2.9\ \mathrm{mm}$，与表中表面向内约
$1\ \mathrm{cm}$ 的范围内才出现明显失水在量级上一致，更深处的内部尚未受到影响。

\subsection{问题二模型的建立}

\textbf{1. 分段物性参数与阶段切换}

与问题一仅涉及预热平衡阶段不同，问题二覆盖持续 $2\sim3$ 天的完整烘干过程，预热平衡与恒温

需要强调的是，恒温干燥阶段的 $\rho,c_p,k$ 均随水分浓度 $C$ 变化，$D$ 同时依赖 $C$ 与温度 $T$
（含 Arrhenius 型温度项）。因此 $\rho,c_p$ 不能再提到时间导数之外，传热方程与传质方程
\textbf{双向耦合}，必须联立求解，这是本问与问题一在模型结构上的本质区别。

\textbf{2. 计算域与三维控制方程}

问题一将药材退化为无限长圆柱，其依据是 $30\ \mathrm{min}$ 的预热时间尺度远小于轴向扩散的
特征时间。但恒温干燥阶段持续数天，轴向端面的对流交换将经轴向扩散逐步向内部渗透，端部效应
不再可以忽略；同时物性随 $C,T$ 变化，方程本身也不再有严格的轴对称简化依据。为严格保留各
控制体的真实通量与边界面积，本问\textbf{不再作降维处理}，直接在柱坐标 $(r,\varphi,z)$ 下
建立完整三维模型~\cite{ref1}。

计算域为整个圆柱体

\begin{equation}
\Omega=\left\{(r,\varphi,z):0\le r\le R,\ 0\le\varphi<2\pi,\
-\tfrac{L}{2}\le z\le\tfrac{L}{2}\right\},
\label{eq:p2domain}
\end{equation}

其中半径 $R=0.02\ \mathrm{m}$、长度 $L=0.25\ \mathrm{m}$，与问题一保持一致。

由能量守恒与质量守恒，控制方程写成守恒（散度）形式

\begin{equation}
\rho c_p\frac{\partial T}{\partial t}=\nabla\cdot(k\nabla T),
\qquad
\frac{\partial C}{\partial t}=\nabla\cdot(D\nabla C).
\label{eq:p2governing}
\end{equation}

利用柱坐标下的梯度与散度算子~\cite{ref2}展开，得径向、周向、轴向三个方向均保留的控制方程

\begin{equation}
\rho c_p\frac{\partial T}{\partial t}
=\frac{1}{r}\frac{\partial}{\partial r}\!\left(rk\frac{\partial T}{\partial r}\right)
+\frac{1}{r^{2}}\frac{\partial}{\partial \varphi}\!\left(k\frac{\partial T}{\partial \varphi}\right)
+\frac{\partial}{\partial z}\!\left(k\frac{\partial T}{\partial z}\right),
\label{eq:p2heat3d}
\end{equation}

\begin{equation}
\frac{\partial C}{\partial t}
=\frac{1}{r}\frac{\partial}{\partial r}\!\left(rD\frac{\partial C}{\partial r}\right)
+\frac{1}{r^{2}}\frac{\partial}{\partial \varphi}\!\left(D\frac{\partial C}{\partial \varphi}\right)
+\frac{\partial}{\partial z}\!\left(D\frac{\partial C}{\partial z}\right).
\label{eq:p2mass3d}
\end{equation}

\textbf{3. 初始条件与边界条件}

初始时刻药材内部温度与水分浓度均匀：

\begin{equation}
T(r,\varphi,z,0)=T_0=28\ ^\circ\mathrm{C},\qquad
C(r,\varphi,z,0)=C_0=2.55\ \mathrm{kg/kg}.
\label{eq:p2ic}
\end{equation}

药材侧面 $r=R$ 与两个端面 $z=\pm L/2$ 均直接暴露于烘房环境，采用对流换热与对流传质条件：

\begin{equation}
-k\left.\frac{\partial T}{\partial n}\right|_{\Gamma}=h\left[T_{\Gamma}-T_a(t)\right],
\qquad
-D\left.\frac{\partial C}{\partial n}\right|_{\Gamma}=h_m\left[C_{\Gamma}-C_a(t)\right],
\label{eq:p2bc}
\end{equation}

其中 $\Gamma$ 表示外边界，$\partial/\partial n$ 为外法向导数，
$h=25\ \mathrm{W/(m^2\cdot K)}$，$h_m=8\times10^{-7}\ \mathrm{m/s}$。周向采用
\textbf{周期性边界}；轴线 $r=0$ 处控制体自然退化，不存在额外的边界面，故无需附加条件。
环境温度与空气含湿量 $T_a(t),C_a(t)$ 由附件1按时间线性插值给出，附件1给定范围之外按
问题一中由附件1确定的恒温段平台值外推。

\textbf{4. 阶段分界时刻 $t_c$ 的稳态统计判定}

分段物性的切换点 $t_c$ 必须依据实测数据客观确定。若采用单一温度阈值（例如烘房温度达到
平台值的 $95\%$ 或 $99.5\%$），容易被测温噪声提前触发，也无法保证此后烘房确实保持恒温。
为此，本文同时检查“接近平台”与“升温速率足够小”两个条件，并附加持续性要求，步骤如下。

\textbf{第 1 步（估计平台）}：用附件1中 $t\ge 10800\ \mathrm{s}$ 的尾段数据估计恒温平台。
需要强调，本步的尾段统计量一律取自\textbf{原始}实测数据——$\sigma$ 应反映真实的测量噪声；
若改用平滑序列的 MAD，量到的只是滤波器自身的平坦度（$\sigma$ 会被压小约 $7$ 倍、稳态带随之
收紧，临界时刻将被人为推迟）。即：\textbf{对流边界条件用平滑序列，阶段判定用原始序列}。
为降低异常波动的影响，平台中心取中位数，噪声尺度取 MAD（中位数绝对偏差）换算的稳健标准差：

\begin{equation}
T^{*}=\operatorname{median}(T_a),\qquad
\sigma=1.4826\cdot\operatorname{median}\left|T_a-T^{*}\right|.
\label{eq:p2mad}
\end{equation}

\textbf{第 2 步（滑动统计量）}：对每个候选时刻 $\tau$，用区间 $[\tau-1200,\ \tau]$（即
$20\ \mathrm{min}$）内的观测值计算滑动均温 $\bar T(\tau)$，并用最小二乘估计升温斜率
$\beta(\tau)$（单位 $^\circ\mathrm{C/min}$）：

\begin{equation}
\bar T(\tau)=\frac{1}{n}\sum_{j=1}^{n}T_a(t_j),\qquad
\beta(\tau)=\frac{\sum_{j}\left(t_j-\bar t\right)\left[T_a(t_j)-\bar T(\tau)\right]}
{\sum_{j}\left(t_j-\bar t\right)^{2}}.
\label{eq:p2slope}
\end{equation}

\textbf{第 3 步（双条件与持续性）}：候选点 $\tau$ 须同时满足

\begin{equation}
\left|\bar T(\tau)-T^{*}\right|\le 2\sigma,
\qquad
\left|\beta(\tau)\right|\le \frac{3\sigma}{20},
\label{eq:p2crit}
\end{equation}

且上述两个条件在 $\tau$ 之后\textbf{连续保持} $1800\ \mathrm{s}$。第一个合格的候选点即定义为
临界时刻 $t_c$。该持续性判断属于离线识别：用后续 $30\ \mathrm{min}$ 的数据确认 $\tau$ 确实
进入稳定段，但将阶段分界\textbf{回标}到 $\tau$；若用于实时控制，则只能在
$\tau+1800\ \mathrm{s}$ 才能确认，不能提前获知未来数据。

由附件1数据计算，各统计量汇总于表~\ref{tab:p2crit}，识别结果为
$t_c=6780\ \mathrm{s}=1.8833\ \mathrm{h}$。

\textbf{5. 分段物性的连续切换}

临界点处\textbf{只切换物性参数，不重新赋初值}：温度场与水分浓度场在切换处继承前一步的结果，
因而状态连续。数值实现上，若某时间步跨越 $t_c$，程序先把该步\textbf{截断}到 $t_c$，下一步
再启用附录3的物性公式，从而避免把同一个时间步同时解释为两个阶段。这样既保证了物性切换的
物理含义明确，又避免了切换处的数值振荡。

\subsection{问题二模型的求解}

\textbf{1. 数值方法}

采用\textbf{有限体积法}在三维柱坐标控制体上离散方程~\eqref{eq:p2heat3d}、
\eqref{eq:p2mass3d}：径向 $20$、周向 $6$、轴向 $32$，共 $20\times6\times32=3840$ 个控制体，
控制体体积由 $r\Delta r\Delta\varphi\Delta z$ 精确给出，径向、周向、轴向的面通量均按真实
几何面积计算。相邻控制体之间的面通量采用\textbf{调和平均}折算的面导率，以正确反映串联的
导热（扩散）阻力；位于边界的控制体保留半网格内部阻力与外对流阻力串联的等效边界导率，
而非直接以控制体中心值近似表面值。

时间方向采用\textbf{后向欧拉}（隐式）格式，时间步长 $\Delta t=5\ \mathrm{s}$；由于热容
$\rho c_p$ 与扩散系数 $D$ 均随 $C,T$ 变化，每一步内采用 \textbf{Picard 迭代}（滞后系数）
更新温度、水分浓度与物性，收敛判据取

\begin{equation}
\max\left(\frac{\left\|\Delta T\right\|_{\infty}}{50},\
\frac{\left\|\Delta C\right\|_{\infty}}{2.55}\right)<10^{-8},
\label{eq:p2tol}
\end{equation}

即温度与水分浓度的相对变化同时足够小。每一步的线性方程组为对称正定稀疏系统，采用
\textbf{共轭梯度法}配合对角预条件求解。求解流程见算法~\ref{alg:p2}。

\begin{algorithm}[H]
\caption{问题二完整烘干过程三维传热--传质数值求解}
\label{alg:p2}
\begin{algorithmic}[1]
\State 初始化：$T\gets T_0$，$C\gets C_0$，$t\gets 0$，组装三维控制体几何量
\State 由附件1按式~\eqref{eq:p2mad}--\eqref{eq:p2crit} 识别临界时刻 $t_c$
\While{$t<t_{\mathrm{end}}$}
    \State $t_{\mathrm{new}}\gets\min(t+\Delta t,\ t_{\mathrm{end}})$
    \If{$t<t_c<t_{\mathrm{new}}$}
        \State $t_{\mathrm{new}}\gets t_c$ \Comment{时间步截断到阶段分界}
    \EndIf
    \State 由 $t_{\mathrm{new}}$ 插值得到环境 $T_a(t),C_a(t)$
    \State 按 $t<t_c$ 与否选择附录2或附录3的物性公式
    \For{$m=1$ \textbf{to} $M_{\max}$} \Comment{Picard 迭代}
        \State 以调和平均组装三维有限体积系数矩阵与等效边界导率
        \State 后向欧拉求解温度场 $T^{n+1}$
        \State 由 $T^{n+1},C^{n}$ 更新 $D$，求解水分浓度场 $C^{n+1}$
        \If{式~\eqref{eq:p2tol} 成立}
            \State \textbf{break}
        \EndIf
    \EndFor
    \State $t\gets t_{\mathrm{new}}$
\EndWhile
\State 提取中截面径向剖面，输出表~\ref{tab:T2}、\ref{tab:C2} 与 result2.xlsx
\end{algorithmic}
\end{algorithm}

最终输出圆柱\textbf{中截面}上从轴线到侧面的径向结果，距离取
$0,0.1,\dots,2.0\ \mathrm{cm}$ 共 $21$ 个位置。其中轴线值与侧面值由外推与边界条件给出：
轴线处由径向抛物线外推 $T(0)=\bigl[9\tilde T_1-\tilde T_2\bigr]/8$，侧面处由对流边界条件
\eqref{eq:p2bc} 反解得到；中间位置由控制体中心值线性插值。

\textbf{3. 结果分析}

\textbf{（1）阶段分界的影响。}临界点 $6780\ \mathrm{s}=1.8833\ \mathrm{h}$ 位于 $1.5\ \mathrm{h}$
与 $2.0\ \mathrm{h}$ 之间，因此前 $3\ \mathrm{h}$ 的结果中，前 $1.5\ \mathrm{h}$ 完全由预热
平衡参数主导，$2.0\ \mathrm{h}$ 之后开始包含恒温干燥参数的作用。由表~\ref{tab:T2} 可见，
$1.5\ \mathrm{h}$ 至 $2.0\ \mathrm{h}$ 之间中心温度由 $47.1226\ ^\circ\mathrm{C}$ 升至
$49.0152\ ^\circ\mathrm{C}$，升温速率已明显放缓，与烘房温度趋于恒定的过程一致。

\textbf{（2）温度场。}药材温度整体由侧面与端面向内部传递，早期径向温差显著、随后趋于均匀：
$0.5\ \mathrm{h}$ 时表面与中心的温差达 $36.7750-33.5769=3.20\ ^\circ\mathrm{C}$，
至 $3.0\ \mathrm{h}$ 已收缩至 $49.9594-49.8952=0.06\ ^\circ\mathrm{C}$。$3\ \mathrm{h}$ 时
中心温度 $49.8952\ ^\circ\mathrm{C}$、侧面温度 $49.9594\ ^\circ\mathrm{C}$，均与烘房平台温度
$50\ ^\circ\mathrm{C}$ 相差不足 $0.11\ ^\circ\mathrm{C}$，说明预热阶段结束时药材已基本热透，
温度场接近均匀，此后温度对水分迁移的影响主要通过 $D$ 的 Arrhenius 项体现。由图~\ref{fig:p2temp}
的热力图可见，色带以竖直方向（等温线沿轴向）为主，说明温度差异主要沿径向发展；临界时刻虚线
两侧颜色平滑过渡，表明临界点处只切换物性参数、温度场本身保持连续，不出现跳跃。右图的径向
剖面进一步给出直观的对比：$0.5\ \mathrm{h}$ 时曲线明显上翘（中心低、表面高），$1\ \mathrm{h}$、
$1.5\ \mathrm{h}$ 曲线依次抬升并趋于平缓，至 $2\ \mathrm{h}$ 以后各条曲线已彼此接近且几乎水平，
反映温度场由“外热内冷”逐步走向均匀。

\textbf{（3）水分浓度场。}水分浓度呈现明显的“内湿外干”径向梯度：$3\ \mathrm{h}$ 时中心
含水率为 $1.9237\ \mathrm{kg/kg}$，而侧面已降至 $1.0791\ \mathrm{kg/kg}$，径向差值达
$0.84\ \mathrm{kg/kg}$。这是因为表面失水由对流传质边界直接控制，而内部水分只能依靠扩散
缓慢外移，后者是控速环节。由图~\ref{fig:p2moist} 的热力图可见，色带以水平方向为主且左侧
（近轴线）始终偏黄、右侧（近表面）逐渐转深，说明含水率梯度主要沿径向分布；随时间的推进
整体颜色由黄转青、由青转紫，即含水率全断面整体下降。右图的径向剖面呈典型的“内高外低”
下凹形状，且随时间的推进整条曲线依次下移：$0.5\ \mathrm{h}$ 时曲线只在最外侧明显下落，
$2\ \mathrm{h}$、$3\ \mathrm{h}$ 时连中心区域也开始下降，说明干燥过程由表及里逐步推进。
临界时刻虚线两侧色带连续，与温度场一样未出现重置或跳变。

需要注意的是，表~\ref{tab:C2} 中$r=2\ \mathrm{cm}$（侧面）处的含水率并非单调下降，而是在
$1.05\sim1.51\ \mathrm{kg/kg}$ 之间波动。这是由侧面值需经对流边界条件~\eqref{eq:p2bc} 反解、
而其中的传质系数 $h_m$、扩散系数 $D$ 与烘房空气含湿量 $C_a(t)$ 均在时段内变化所致；同时
$t_c$ 前后的分段物性切换也会使表层薄层的平衡值发生小幅度调整。径向内侧（$r\le1.5\ \mathrm{cm}$）
的含水率则始终单调下降，不受该边界处理影响，符合物理预期。

\textbf{（4）判据的适用性。}本文将“是否进入恒温阶段”的判定建立在平台接近程度、升温斜率与
持续时间三项证据上，比单一进度阈值更能抵抗测温波动。但阈值 $2\sigma$、$3\sigma/\text{窗长}$
以及 $20/30$ 分钟的时间参数仍是建模选择，正式应用时应结合设备的控温精度与工艺容差做灵敏度
检验。

\subsection{问题三模型的建立}

\textbf{1. 二维轴对称模型}

问题三要求在完整烘干过程基础上确定药材内部所有位置均达到
$C_{\mathrm{crit}}=0.15\ \mathrm{kg/kg}$ 的最早时刻。圆柱药材关于轴线对称，且主要传热传质
过程由侧面和两个端面控制，因此采用二维轴对称模型，计算域为

\begin{equation}
\Omega=\left\{(r,z):0\le r\le R,\ 0\le z\le L\right\},
\label{eq:p3domain}
\end{equation}

其中

\begin{equation}
R=0.02\ \mathrm{m},\qquad L=0.25\ \mathrm{m}.
\label{eq:p3geometry}
\end{equation}

温度场 $T(r,z,t)$ 满足变物性热传导方程

\begin{equation}
\rho(C)c_p(C)\frac{\partial T}{\partial t}
=
\frac{1}{r}\frac{\partial}{\partial r}
\left(rk(C)\frac{\partial T}{\partial r}\right)
+
\frac{\partial}{\partial z}
\left(k(C)\frac{\partial T}{\partial z}\right),
\label{eq:p3heat}
\end{equation}

干基水分浓度 $C(r,z,t)$ 满足

\begin{equation}
\frac{\partial C}{\partial t}
=
\frac{1}{r}\frac{\partial}{\partial r}
\left(rD(C,T)\frac{\partial C}{\partial r}\right)
+
\frac{\partial}{\partial z}
\left(D(C,T)\frac{\partial C}{\partial z}\right).
\label{eq:p3mass}
\end{equation}

依据附录3，物性参数取

\begin{equation}
\rho(C)=650+128C,
\label{eq:p3rho}
\end{equation}

\begin{equation}
c_p(C)=1450+2736\frac{C}{C+1},
\label{eq:p3cp}
\end{equation}

\begin{equation}
k(C)=0.21+0.38\frac{C}{C+1},
\label{eq:p3k}
\end{equation}

\begin{equation}
D(C,T)=2.4\times10^{-3}
\exp\left(-\frac{0.45}{C}\right)
\exp\left(-\frac{3850}{T}\right),
\label{eq:p3D}
\end{equation}

其中 $T$ 使用开尔文温度。

\textbf{2. 初始条件与边界条件}

初始温度和水分浓度均匀：

\begin{equation}
T(r,z,0)=28\ ^\circ\mathrm{C},\qquad
C(r,z,0)=2.55\ \mathrm{kg/kg}.
\label{eq:p3ic}
\end{equation}

中心轴采用轴对称条件：

\begin{equation}
\frac{\partial T}{\partial r}(0,z,t)=0,\qquad
\frac{\partial C}{\partial r}(0,z,t)=0.
\label{eq:p3axis}
\end{equation}

侧面 $r=R$ 和两个端面 $z=0,\ L$ 均采用对流换热与对流传质边界：

\begin{equation}
-k(C)\frac{\partial T}{\partial n}
=
h\left[T-T_\infty(t)\right],
\label{eq:p3heatbc}
\end{equation}

\begin{equation}
-D(C,T)\frac{\partial C}{\partial n}
=
h_m\left[C-C_\infty(t)\right].
\label{eq:p3massbc}
\end{equation}

其中 $T_\infty(t)$、$C_\infty(t)$ 由附件1按时间插值得到，$h=25\ \mathrm{W/(m^2\cdot K)}$，
$h_m=8\times10^{-7}\ \mathrm{m/s}$。

\textbf{3. 预热与恒温阶段分界}

问题三沿用问题二中的阶段识别方法：以附件1尾部数据的中位数作为平台温度，以 MAD
换算稳健标准差，并通过 $20\ \mathrm{min}$ 滑动均值和最小二乘升温斜率的双条件及后续
$30\ \mathrm{min}$ 持续性要求确定临界时刻。由原始附件数据得到
$t_c=6780\ \mathrm{s}=1.8833\ \mathrm{h}$，与问题二识别结果完全一致，故本问全程沿用
同一分界，不再另行判定。

\subsection{问题三的求解与结果分析}

\textbf{1. 有限体积离散（守恒格式）}

相邻控制体在同一内部面上使用大小相等、方向相反的通量。将全部控制体求和后，内部面通量
严格抵消，只保留侧面和两个端面的边界传质通量：

\begin{equation}
F_{\mathrm{surface}}
=
h_m\left(C_\infty-C_{\mathrm{surface}}\right)dA.
\label{eq:p3boundaryflux}
\end{equation}

该格式从离散层面保证全局水分守恒。

\textbf{2. 隐式 RK4 时间推进}

温度与水分浓度组成统一状态向量，采用二阶段 Gauss--Legendre 隐式 RK4。Butcher 系数为

\begin{equation}
c_1=\frac12-\frac{\sqrt3}{6},\qquad
c_2=\frac12+\frac{\sqrt3}{6},
\label{eq:p3rk4c}
\end{equation}

\begin{equation}
A=
\begin{pmatrix}
\frac14 & \frac14-\frac{\sqrt3}{6}\\
\frac14+\frac{\sqrt3}{6} & \frac14
\end{pmatrix},
\qquad
b=
\begin{pmatrix}
\frac12 & \frac12
\end{pmatrix}.
\label{eq:p3rk4ab}
\end{equation}

隐式阶段方程为

\begin{equation}
Y_i
=
U_n
+
\Delta t\sum_{j=1}^{2}a_{ij}
F\left(t_n+c_j\Delta t,Y_j\right).
\label{eq:p3stages}
\end{equation}

采用阻尼固定点迭代求解：

\begin{equation}
Y_i^{(k+1)}
=
(1-\omega)Y_i^{(k)}
+
\omega\left[
U_n+\Delta t\sum_{j=1}^{2}a_{ij}
F\left(t_n+c_j\Delta t,Y_j^{(k)}\right)
\right].
\label{eq:p3fixedpoint}
\end{equation}

取 $\omega=0.8$，收敛判据为

\begin{equation}
\max_i\left\|Y_i^{(k+1)}-Y_i^{(k)}\right\|_\infty
<
1.0\times10^{-7}.
\label{eq:p3tolerance}
\end{equation}

时间步长取 $\Delta t=2.5\ \mathrm{s}$。当检测到全空间最大水分浓度首次降到
$0.15\ \mathrm{kg/kg}$ 以下时，对相邻两个时刻进行线性插值，得到精确的烘干结束时间。

\textbf{3. 结果}

计算得到药材内部所有位置均满足 $C<0.15\ \mathrm{kg/kg}$ 的时间为

\begin{equation}
t_{\mathrm{dry}}=56.9702\ \mathrm{h}.
\label{eq:p3drytime}
\end{equation}

此时全空间最大水分浓度为

\begin{equation}
C_{\max}=0.144606\ \mathrm{kg/kg}.
\label{eq:p3finalmax}
\end{equation}

\section{模型优缺点分析}
\subsection{优点}
\begin{itemize}
    \item \textbf{模型复杂度与问题尺度相匹配}：问题一依据 $L/R=12.5$ 作一维降维、问题二因
    长时程端部效应保留完整三维、问题三利用轴对称性回到二维，既避免了“一律三维”造成的计算
    浪费（问题二全量 $3\ \mathrm{h}$ 仿真仅约 $9\ \mathrm{s}$），也避免了过度简化导致失真。

    \item \textbf{离散格式守恒、边界处理精细}：采用守恒型有限体积法，控制体体积与面通量均按
    真实几何量计算；内部面导率用调和平均折算，边界面用“半网格内部阻力与外对流阻力串联”的
    等效导率，而非以控制体中心值近似表面值，从而避免了后者带来的一阶误差。

    \item \textbf{阶段分界判据客观、抗噪且可复现}：以尾段中位数与 MAD 稳健标准差给出稳态温度
    带，再结合滑动均温与升温斜率双条件及持续性要求判定 $t_c$，比单一进度阈值更能抵抗测温噪声；
    敏感性检验表明三个互不相关的松紧变体给出完全相同的 $t_c$。

    \item \textbf{数值方案稳定且精度可控}：时间方向采用隐式格式（Crank--Nicolson、后向欧拉、
    隐式 RK4），对刚性扩散问题无条件稳定，适合 $2\sim3$ 天的长时间推进；非线性系数以 Picard
    迭代线性化，收敛判据同时约束温度与含水率的相对变化。

    \item \textbf{结果的不确定度已量化}：通过空间网格加密、时间步缩小、$t_c$ 判据阈值扰动三组
    算例给出偏差量级，并将全域偏差定位到边界反解层，使结论的可靠范围明确可辨。
\end{itemize}

\subsection{缺点与改进方向}
\begin{itemize}
    \item \textbf{缺少实测内部数据用于标定与验证}：附件仅给出烘房环境条件，没有药材内部温度
    与含水率的实测值，模型只能在机理与数值层面作自洽检验。改进方向：增设少量内部测点，用其
    反演 $h_m$、$D$ 等难以准确给定的参数，并对模型做实测校验。

    \item \textbf{物性参数做了常数化处理}：问题一至问题三中 $h$、$h_m$ 取常数，未考虑风速与
    表面含水率的影响；预热阶段亦忽略了温度对扩散系数的 Arrhenius 效应。改进方向：改用
    $h_m=f(u)$、$D=D(C,T)$ 的一般形式。

    \item \textbf{热质耦合仍不完备}：模型未计入表面水分汽化带走的热量（相变潜热），也未考虑
    干燥收缩引起的孔隙结构变化对扩散系数的影响，这在干燥后期含水率很低时可能带来偏差。改进
    方向：在表面能量平衡中加入汽化潜热项，并把孔隙率变化引入有效扩散系数。

    \item \textbf{结果的位数表述需谨慎}：收敛性检验表明表列数值自第 3 位小数起已不具收敛
    意义，故正文的物理解释均建立在 $10^{-2}$ 量级的差异上，未对更低位小数作实质性推断。

    \item \textbf{判据阈值仍属建模选择}：$2\sigma$ 温度带、$20\ \mathrm{min}$ 窗长与
    $30\ \mathrm{min}$ 持续性要求缺少设备控温精度与工艺容差的支撑，实际应用前应结合具体烘房
    条件作标定与灵敏度复核。
\end{itemize}

# Control-volume geometry (factor pi cancelled out):
#   V_i = r_{i+1/2}^2 - r_{i-1/2}^2
#   A_{i+1/2} = 2 r_{i+1/2}
rp = (np.arange(N + 1) + 0.5) * dr
rm = (np.arange(N + 1) - 0.5) * dr
V = np.zeros(N + 1)
V[0]   = (dr / 2.0) ** 2
V[1:N] = rp[1:N] ** 2 - rm[1:N] ** 2
V[N]   = R ** 2 - rm[N] ** 2
Ap, Am = 2.0 * rp, 2.0 * rm

def solve_mass(C_old, dt, Cair_new, Cair_old, theta=0.5):
    """Moisture: Crank-Nicolson (theta=0.5) with
    Picard iteration for nonlinear D(C)."""
    def build(C):
        # face diffusivity from cell averages
        Dp = D_coeff(0.5 * (C[:-1] + C[1:]))
        Dm = np.zeros(N + 1); Dm[1:] = Dp
        a, b, c = (np.zeros(N + 1), np.zeros(N + 1),
                   np.zeros(N + 1))
        a[1:N] =  Dm[1:N] * Am[1:N] / dr
        c[1:N] =  Dp[1:N] * Ap[1:N] / dr
        b[1:N] = -(Dp[1:N] * Ap[1:N]
                   + Dm[1:N] * Am[1:N]) / dr
        c[0] =  Dp[0] * Ap[0] / dr
        b[0] = -Dp[0] * Ap[0] / dr       # symmetry at r = 0
        a[N] =  Dm[N] * Am[N] / dr
        b[N] = -Dm[N] * Am[N] / dr \
               - 2.0 * R * hm            # Robin at r = R
        return a, b, c
    a0, b0, c0 = build(C_old)
    LCold = apply(a0, b0, c0, C_old)   # explicit part, frozen
    mdt = V / dt
    C_new = C_old.copy()
    for _ in range(3):                 # Picard iterations
        a, b, c = build(C_new)
        rhs = (mdt * C_old + (1.0 - theta) * LCold
               + theta * S_next + (1.0 - theta) * S_old)
        C_new = self._thomas(mdt - theta * b,
                             -theta * a, -theta * c, rhs)
    return C_new
\end{lstlisting}

\begin{lstlisting}[caption={问题二：三维控制体导率组装与隐式求解（节选）}]
def matrix(self, coefficient, h):
    # Interior faces: harmonic mean reflects
    # the series conduction resistance
    g = (self.g * 2 * coefficient[self.i]
         * coefficient[self.j]
         / (coefficient[self.i] + coefficient[self.j]))
    # Boundary faces: half-cell internal resistance
    # in series with the external film
    b = self.boundary_area / (
        self.boundary_distance / coefficient[self.boundary_ids]
        + 1 / h)
    diagonal  = np.bincount(self.i, g, minlength=len(coefficient))
    diagonal += np.bincount(self.j, g, minlength=len(coefficient))
    diagonal += np.bincount(self.boundary_ids, b,
                            minlength=len(coefficient))
    K = coo_matrix((-np.r_[g, g],
                    (np.r_[self.i, self.j],
                     np.r_[self.j, self.i])),
                   shape=(len(coefficient), len(coefficient))).tocsr()
    return K + diags(diagonal), np.bincount(
        self.boundary_ids, b, minlength=len(coefficient))

def implicit_step(self, old, guess, storage,
                  coefficient, h, ambient, dt):
    K, b = self.matrix(coefficient, h)
    m = storage * self.volume / dt
    A = K + diags(m)                   # backward Euler system
    inv = 1 / A.diagonal()
    # Jacobi preconditioner
    M = LinearOperator(A.shape, matvec=lambda x: inv * x)
    value, info = cg(A, m * old + b * ambient,
                     x0=guess, M=M,
                     rtol=1e-9, atol=1e-12, maxiter=900)
    if info != 0:
        raise RuntimeError(
            "linear iteration did not converge (info=%d)" % info)
    return value
\end{lstlisting}

\begin{lstlisting}[caption={问题二：阶段分界时刻 $t_c$ 的稳健统计判定}]
def detect_critical_time(air, tail_start=10800,
                         window=1200, persistence=1800):
    """Plateau from the median, noise scale from the MAD,
    then require the 20-min mean and the least-squares
    slope to stay inside the band for 30 min."""
    t, temperature = air[:, 0], air[:, 1]
    sample_dt = float(np.median(np.diff(t)))
    tail    = temperature[t >= tail_start]
    plateau = float(np.median(tail))
    # robust standard deviation
    sigma   = float(1.4826 * np.median(np.abs(tail - plateau)))
    n_win  = int(round(window / sample_dt)) + 1
    n_keep = int(round(persistence / sample_dt)) + 1
    mean  = np.full(len(t), np.nan)
    slope = np.full(len(t), np.nan)
    for j in range(n_win - 1, len(t)):
        sl = slice(j - n_win + 1, j + 1)
        minutes = (t[sl] - t[sl][0]) / 60
        mean[j]  = temperature[sl].mean()
        slope[j] = np.polyfit(minutes, temperature[sl], 1)[0]
    band        = 2 * sigma
    slope_limit = 3 * sigma / (window / 60)
    stable = ((np.abs(mean - plateau) <= band)
              & (np.abs(slope) <= slope_limit))
    for j in range(n_win - 1, len(t) - n_keep + 1):
        if np.all(stable[j:j + n_keep]):   # persistence check
            return float(t[j]), {"plateau": plateau,
                                 "sigma": sigma, "band": band,
                                 "slope_limit": slope_limit}
    raise RuntimeError("no steady stage found in Attachment 1")
\end{lstlisting}
